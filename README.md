# Mon Petit Budget – versions publiées

Ce dépôt contient uniquement les **installeurs** de Mon Petit Budget, une application de suivi de budget qui fonctionne entièrement sur ton appareil. Le code source n'est pas public.

Toutes les versions : **[Releases](https://github.com/PeterNanot/mon-petit-budget-releases/releases/latest)**.

## Windows

1. Télécharge `Mon-Petit-Budget-Setup-x.y.z.exe`.
2. Lance-le. Windows peut afficher « Windows a protégé votre ordinateur », car l'installeur n'est pas signé : clique sur **Informations complémentaires**, puis **Exécuter quand même**.

Windows 10 ou 11 (64 bits). Mise à jour ensuite depuis l'application : **engrenage → Rechercher une mise à jour** (le seul moment où elle se connecte à internet, sans rien envoyer).

## Android

1. Depuis le téléphone, télécharge `Mon-Petit-Budget-x.y.z.apk`.
2. Ouvre-le. Android demande d'autoriser ton navigateur (ou ton gestionnaire de fichiers) à **installer des applis inconnues** : accepte pour cette source, puis **Installer**.
3. Pour une nouvelle version, installe le nouvel APK par-dessus : tes données sont conservées.

Android 6 ou plus récent. Un widget d'écran d'accueil (« Disponible du jour ») est proposé dans la liste des widgets.

## Tes données

Elles restent sur ton appareil (PC : `Documents\BudgetApp` par défaut ; Android : l'espace privé de l'application) et ne sont jamais envoyées nulle part. Une mise à jour ne les touche pas.
