# Mon Petit Budget – versions publiées

Ce dépôt contient uniquement les **installeurs Windows** de Mon Petit Budget, une application de suivi de budget qui fonctionne entièrement sur ton ordinateur. Le code source n'est pas public.

## Installer

1. Ouvre la page **[Releases](https://github.com/PeterNanot/mon-petit-budget-releases/releases/latest)** et télécharge `Mon-Petit-Budget-Setup-x.y.z.exe`.
2. Lance-le. Windows peut afficher « Windows a protégé votre ordinateur », car l'installeur n'est pas signé : clique sur **Informations complémentaires**, puis **Exécuter quand même**.

Windows 10 ou 11 (64 bits) uniquement.

## Mettre à jour

Dans l'application : **engrenage → Rechercher une mise à jour**. C'est le seul moment où l'application se connecte à internet : elle lit ici le numéro de la dernière version, sans envoyer aucune de tes données.

## Tes données

Elles restent sur ton ordinateur (par défaut dans `Documents\BudgetApp`) et ne sont jamais envoyées nulle part. Une mise à jour ou une désinstallation ne les touche pas.
